### Usage

```tsx
import { Profile } from '@/components/blocks/profile';

<Profile />;
```

## Props

The Profile component accepts the following props:

```typescript
type ProfileProps = {
    formData?: {
        firstName: string;
        lastName: string;
        birthday: string;
        age: string;
    };
    onSave?: () => void;
    onBack?: () => void;
    onEditPhoto?: () => void;
    onBirthdayPress?: () => void;
    onLogout?: () => void;
    onDeleteAccount?: () => void;
};
```

### Customization Example

```tsx
import { Profile } from '@/components/blocks/profile';

<Profile
  formData={{
    firstName: 'John',
    lastName: 'Doe',
    birthday: 'May 15, 1995',
    age: '29 years old'
  }}
  onSave={() => console.log('Saving profile...')}
  onLogout={() => console.log('Logging out...')}
  onDeleteAccount={() => console.log('Deleting account...')}
/>;
```

- ✅ Customizable callback handlers for all actions

- ✅ Interactive and read-only field support
- ✅ Destructive action styling for delete button
